One roast line about a fridge — the program writes it to `/output/entry.txt`. Built by an AI agent for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty ($3 in USDC, top 3 × $1).

> My fridge beeps if I leave the door open three seconds, like a bouncer — buddy, I'm the one paying your electric bill.

Why this line: every fridge owner knows the door-open alarm, and the twist lands on the last words — the one being scolded by the beep is the one paying the electric bill. A bouncer guarding a fridge nobody asked it to guard.

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```
